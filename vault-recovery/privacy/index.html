Privacy

Effective October 7, 2026.

Vault Recovery processes information selected by its owner to create and verify encrypted backups.

With permission, it uses Google Drive to create and manage backup files associated with the app. It does not request access to all Drive files. Backup content is encrypted locally before upload.

Google processes stored files to provide its services. Information is not sold or used for advertising. The owner can revoke access and delete backups; revoking access does not delete existing copies.

Use of Google data follows the Google API Services User Data Policy, including applicable Limited Use requirements.

This website contains no backups, credentials or forms. Hosting providers may retain ordinary request logs. For privacy questions, use the support address on the app’s Google consent screen.
